# Этап 3, Prisma

Для начала, нам нужен клиент Prisma. Его можно получить введя команду `prisma generate`, или, в нашем случае, это будет выглядеть как `docker-compose exec app yarn prisma:generate`

## Singleton для dev режима

Инициализация клиента в файле `src/lib/prisma.ts` происходит не совсем стандартно, в dev режиме нам приходится записывать эксземпляр клиента в глобальную переменную, так как из-за работы nodedemon экземляры будут создаваться каждый раз заново, порождая новые подключения к БД которые могут оставаться в памяти и в итоге приводить к превышению лимита подключений
