# Этап 0, инициализация и настройка проекта

Более подробная информация так же находится в комментариях внутри файла `docker-compose.yml`

## Запуск

Создайте файл `.env` в корне проекта, или просто скопируйте и переименуйте `.env.example`.

Затем, выполните команду `yarn docker:up` или `docker-compose up -d --build`

Описание .env переменных, звездочкой отмечены обязательные переменные:

```
# Настройки базы данных
---------------------
[*] DB_USER                         =   {Имя пользователя}
[*] DB_PASSWORD=securepassword123   =   {Пароль}
[*] DB_NAME=expressdb               =   {Имя базы данных}
---------------------

# Настройки визуальной панели управления
---------------------
[*] PGADMIN_EMAIL                   =   {Email пользователя для входа в панель}
[*] PGADMIN_PASSWORD                =   {Пароль пользователя для входа в панель}
---------------------

# Права доступа (для пользователей unix)
---------------------
[ ] UID                             =   {ID пользователя}
[ ] GID                             =   {ID группы}
---------------------
```

## Сервисы

Команда запуска docker-compose запустит четыре сервиса

1. **\[localhost:5432\]** Базу данных PostgreSQL
1. **\[localhost:5050\]** pgAdmin, визуальная панель управления базой данных
1. **\[localhost:5555\]** Prisma Studio, визуальная панель управления для Prisma
1. **\[localhost:8000\]** Сервер express

## Сущности

**Express** - библиотека для простого создания серверов на node.js, он будет отвечать у нас за прием и обработку входящих к нему запросов, а так же будет отправлять ответы

**PostgreSQL** - SQL база данных для нашего проекта

**Prisma** - ORM для базы данных. ORM это прослойка между базой данных и нашим кодом, которая абстрагирует нас конкретной базы данных, давая общий интерфейс взаимодействия с ней. Кроме того, ORM позволяет нам не писать запросы к базе вручную, а так же она сама производит оптимизации запросов которые мы делаем. В случае с TypeScript, она так же сгенерирует нам типы данных в нашей БД
