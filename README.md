# Изучение связки Express / Prisma / PostgreSQL / TypeScript

Репозиторий создан с целью изучения принципов работы и написания backend приложений на базе вышеперечисленного стека технологий. 

## Целевая аудитория

Изучение **не рассчитано на новичков** и не содержит подробных объяснений всех нюансов, я являюсь **frontend разработчиком** решившим расширить свои компетенции до **fullstack специалиста**, паралельно осталяя заметки для себя в этом репозитории в кадежде что однажды они понадобятся кому-то еще. 

## Структура

Обучение поделено на несколько этапов, каждый этап представляет из себя ветку с номером этапа (stage-0, stage-1, stage-2 и т.д)

Если этапа со следующим номером нет, значит он пока в процессе ¯\\_(ツ)_/¯ 

README в каждой стадии будет содержать пояснительные материалы согластно текущей стадии, каждая следующая стадия будет выходить из предыдущей, так что если вы делаете какие-то изменения в текущей стадии, теоретически, вы можете просто смерджить ее со следующей стадией, но, конечно, это не защитит вас от возможных конфликтов

## Финальный результат

По итогу у вас получится api для todo-листов (ну а для чего же еще?). Сперва мы сделаем простое хранение наших задач в базе данных, рассмотрим и создадим для этого базовые CRUD опреации, затем будем постепенно усложнять нашу систему, добавляя в нее пользователей, авторизацию, права доступа, связи между таблицами и так далее.

Целью будет освещение как можно большего количества концепций для работы с данными с точки зрения backed, но так чтобы каждая стадия была обособленна от другой и прерваться можно было бы на любой из них, оставаясь при этом с работоспособным кодом.
